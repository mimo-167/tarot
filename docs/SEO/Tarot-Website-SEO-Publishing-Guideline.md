# Tarot Website SEO Publishing Guideline

## Goal

Publish every SEO article using SEO best practices so the website gradually builds topical authority on Google.

## URL Structure

- Use English URLs
- lowercase only
- use "-"
- permanent URL

Example:

```text
/blog/should-i-break-up
/blog/ai-tarot-accurate
```

## Meta

Each article must include:

- Meta Title
- Meta Description
- OpenGraph
- Twitter Card

## Heading Structure

- One H1 only
- H2/H3 hierarchy

## Table of Contents

Automatically generate anchor-linked TOC.

## Internal Links

Automatically recommend 3–5 related articles.

## CTA

End every article with:

Try AI Tarot Reading

Button: Start Reading →
