# Tarot Spreads Specification (tarot_spreads.md)

本文件定义网站所有牌阵，供前端展示、AI调用及产品设计使用。

## 通用规范

每个牌阵包含： - 名称 - 一句话介绍 - 适合问题 - 牌阵示意 -
每张牌位含义 - AI解牌重点

> 注：牌位名称以产品展示为准，AI应结合全部牌位综合分析，而不是逐张孤立解释。

------------------------------------------------------------------------

# 单牌阵

## 一句话介绍

当你只是想获得一个简单直接的建议时。

## 适合的问题

-   今天需要注意什么？
-   我现在最需要知道什么？
-   给我一个建议。

## 牌阵示意

``` text
[1]
```

## 每张牌位含义

-   **① 核心信息**：当前最重要的信息、提醒或建议。

## AI解牌重点

-   结合全部牌位建立故事线。
-   优先解释牌位之间的联系，而不是逐张堆砌牌义。
-   先回答用户问题，再引用牌义支撑结论。
