# 自我探索

## 一句话介绍

帮助你了解自己真正的状态、内在需求与潜意识影响。

## 适合的问题

-   我最近为什么总是迷茫？
-   我真正想要的是什么？
-   我该如何更了解自己？

## 牌阵示意

``` text
        [4]

 [2]         [3]

        [1]
```

## 每张牌位含义

-   **① 我当前的状态**：代表你目前最真实的处境、能量与人生阶段。
-   **②
    我外在的表现**：代表你展现给外界的形象、行为模式，以及别人眼中的你。
-   **③ 我内在的渴望**：代表真正驱动你的需求、愿望与情感动力。
-   **④ 我的潜意识**：代表尚未觉察的信念、惯性、心理模式或深层影响。

## AI解牌重点

-   优先寻找「外在表现」与「内在渴望」是否一致。
-   重点分析潜意识如何影响当前状态。
-   最终帮助用户获得自我觉察，而不是预测未来。
-   给出可以实践的成长建议，而不是抽象的心灵鸡汤。

# 身心灵牌阵

## 一句话介绍

从身体、情绪与精神三个层面，整体了解自己目前的状态。

## 适合的问题

-   为什么最近总觉得很累？
-   我的状态为什么一直不好？
-   我需要先调整哪一个方面？

## 牌阵示意

``` text
        [3]

 [1]         [2]

      [建议]
```

> 建议牌由切牌或额外抽取获得（如产品不使用切牌，可省略）。

## 每张牌位含义

-   **①
    身（身体）**：代表现实生活、健康、行动力、安全感及物质层面的状态。
-   **② 心（心理）**：代表情绪、感受、压力、人际互动及内心活动。
-   **③ 灵（精神）**：代表人生方向、价值观、成长课题、直觉与精神追求。
-   **建议牌（可选）**：代表目前最值得采取的调整方向。

## AI解牌重点

-   不把任何牌义解释为医学诊断。
-   分析「身、心、灵」三者是否失衡。
-   找出最需要优先修复的层面。
-   给出贴近日常生活的改善建议。

# 荣格原型牌阵（进阶）

## 一句话介绍

探索人格面具、潜意识与内在成长方向。

## 适合的问题

-   我真正的性格是什么？
-   我为什么总会重复遇到同样的问题？
-   我有哪些自己没有发现的一面？

## 牌阵示意

``` text
 [1]      [2]

      [5]

 [4]      [3]
```

## 每张牌位含义

-   **① 人格面具（Persona）**：你向世界展示出来的自我。
-   **② 阴影（Shadow）**：被压抑、否认或忽略的自己。
-   **③ 阿尼玛 / 阿尼姆斯**：内在异性原型，对关系模式产生的重要影响。
-   **④ 智慧老人 / 智慧老妇**：内在智慧、经验与成长资源。
-   **⑤ 自性（Self）**：人格整合后的核心方向，也是整个牌阵的中心主题。

## AI解牌重点

-   不做心理诊断。
-   重点寻找人格冲突与成长机会。
-   帮助用户理解自身模式，而不是预测事件。
